# TrustworthyAI_Prototype
# Исследование доверенного ИИ (Trustworthy AI) в рекламных рекомендательных системах

Данный репозиторий содержит материалы магистерской диссертации, посвященной оптимизации моделей машинного обучения для персонализации рекламы с акцентом на этику и доверие (Trustworthy AI).

## 📌 Основная цель
Минимизация «эффекта жуткой рекламы» (creepy effect) и предотвращение утечки сенситивных данных пользователей при сохранении высокой предсказательной способности модели.
Современные методы персонализации часто приводят к возникновению **«creepy effect»**, когда пользователь чувствует избыточную слежку. Это происходит из-за склонности моделей к меморизации (запоминанию) уникальных характеристик пользователей вместо обобщения паттернов.

## 🛠 Технологический стек
* **Framework:** TensorFlow 2.15.0
* **Privacy:** TensorFlow Privacy (алгоритм DP-SGD)
* **Interpretability (XAI):** SHAP (KernelExplainer)
* **Dataset:** Criteo Display Advertising Challenge

## 📂 Структура проекта
* `Ablation_Study_Embeddings_DP.ipynb` — Основной модуль: обучение моделей, исследование размерности эмбеддингов (Ablation Study) и расчет бюджета приватности ($\epsilon$).
* `XAI_Interpretation_and_Results.ipynb` — Модуль анализа: визуализация векторов Шепли (SHAP Beeswarm & Bar plots) и пермутационная важность признаков.
* `models/` — (Исключено из репозитория) Сохраненные веса моделей в формате `.h5`.
* `shap_data/` — (Исключено из репозитория) Кэшированные расчеты SHAP в формате `.pkl`.

## 🔬 Ключевые результаты
1. **Privacy Accounting:** Реализован расчет бюджета приватности. Для выборки $N=300,000$ при шуме $\sigma=0.473$ достигнут уровень $\epsilon=10.0$.
2. **Creepy Effect Mitigation:** С помощью XAI доказано, что внедрение DP-SGD снижает влияние доминирующих признаков в 3.5 раза и подавляет «запоминание» специфических категориальных данных.
3. **Trade-off Analysis:** Проведен замер падения метрики AUC при переходе от базовой к приватной модели.
